# Mes Animaux — Android APK v1.0

Application hors connexion pour enfants, avec 12 animaux, français/anglais/arabe, animation au clic et son généré localement.

## Compiler en APK
- Ouvrir le projet dans Android Studio et lancer `assembleDebug`.
- Ou utiliser un service CI/compilation Android en important ce dossier.

APK attendu: `app/build/outputs/apk/debug/app-debug.apk`
